### A. API Key 弹窗错排

当前实现的 `#credential-form` 只设置 display/grid gap，没有独立定义列布局。全局 `form` 规则设置：

```css
grid-template-columns: .7fr 1fr .7fr 1fr 1.5fr auto;
```

其响应式规则还会改为三列。弹窗的标题、模型服务说明、说明文字、输入框、状态和按钮都是表单的直接子元素，因此进入这些全局网格列，与用户截图的挤压竖排现象一致。

建议范围：
- 为凭据弹窗设置明确的独立单列内容布局，按钮使用专用操作区；
- 控制窗口宽度、视口内最大高度、内部滚动、输入框宽度和长文本换行；
- 验证桌面、900px、390px，以及放大文字/页面缩放、深浅主题；
- 验证关闭/Escape/键盘焦点及保存、删除、错误状态可见；
- 保留 Windows 凭据管理器、密码输入、密钥清空、同源边界、无隐式模型调用等现有行为；
- 增加能够发现列布局挤压的实际弹窗视觉/几何断言，不能只测试按钮能点击。
